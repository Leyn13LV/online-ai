# Online AI

An online AI chat application optimized for iPad without a keyboard, powered by OpenRouter API.

## Features

- 📱 Touch-friendly interface optimized for iPad
- 🎙️ Voice input support using Web Speech API
- 🤖 Access to multiple AI models via OpenRouter
- 💬 Real-time chat interface
- 📱 Fully responsive design
- ⚡ No keyboard required - fully touch-based

## How to Use

1. Open `index.html` in your web browser on your iPad
2. Enter your OpenRouter API key in the settings
3. Select an AI model from the dropdown
4. Type or use voice input to chat with the AI
5. Get responses from the selected AI model

## Setup

No installation needed! Just clone this repo and open `index.html` in a web browser.

### Getting an OpenRouter API Key

1. Visit [openrouter.ai](https://openrouter.ai)
2. Sign up for an account
3. Generate an API key
4. Use it in the application

## Files

- `index.html` - Main application interface
- `style.css` - Styling and responsive design
- `script.js` - Application logic and OpenRouter API integration

## Browser Support

Works on modern browsers supporting:
- Web Speech API (voice input)
- Fetch API
- Local Storage
